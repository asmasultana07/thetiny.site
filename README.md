# thetiny.site

Homepage one-page website structure built with React.js.

## Project Structure

```
thetiny.site/
├── public/
├── src/
│   ├── components/
│   │   ├── Navbar/
│   │   ├── HeroShortener/
│   │   ├── TrustMetric/
│   │   ├── PopularLinks
│   │   ├── PremiumFeatures/
│   │   ├── Pricing/
│   │   ├── Testimonials/
│   │   ├── AnalyticsPreview/
│   │   ├── WhyChoose/
│   │   ├── FAQ/
│   │   ├── Footer/
│   │   └── ui/
│   │       ├── button/
│   │       └── loading/
│   ├── App.css
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── index.html
├── package.json
└── vite.config.js
```

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd thetiny.site
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
